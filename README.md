# Demo Producto Pedido Service

## Descripción
API REST desarrollada con Java y Spring Boot para la gestión de productos y pedidos de una tienda de electrodomésticos (ElectroStore). Implementa operaciones CRUD, relaciones 1:N entre Pedido y DetallePedido, Named Queries, consultas JPQL seguras y un DAO personalizado con EntityManager.

## Tecnologías
- Java 17
- Spring Boot 3.3.4
- Spring Data JPA
- MySQL
- Maven
- Git / GitHub

## Ejecución
./mvnw spring-boot:run
